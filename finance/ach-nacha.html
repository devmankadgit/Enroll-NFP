NACHA File Generation & Transmission
NACHA files use PPD transaction code for individual agents and CCD for agency accounts. File is transmitted to the configured payment processor SFTP on the payment date. Files are retained for 7 years. Balance check is performed before transmission.

ACH Return File — Finance Review Queue
ACH returns are received from the payment processor and must be actioned by Finance. Return codes R02, R03 (closed/no account) automatically set agent banking status to Invalid and hold payment. R07 (authorization revoked) requires Finance review before retry.

Check Disbursement Files
Check files are generated in CSV format and transmitted to the check printing vendor. Agents with no valid mailing address are set to On Hold - Address Gap and excluded from the check file. Both check files and NACHA files are retained for 7 years.
