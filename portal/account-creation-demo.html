1. Payer Admin login, then invite agent

Sign in as Payer Admin (payeradmin / Test@123). After login you land on Agent Invitations inside the carrier portal. Send an invitation and the invitation email preview opens automatically.

3. Accept invitation

Accept the invitation. On the success screen click Open Account Created email (always visible). That opens the Set Password email from email-templates.

Open accept invitation

4. Account created / Set Password email

Uses the email-templates branch pages. CTA Set Password opens the set-password page.

Open Set Password email Open Set Password (brief)

5. Set password - SSO - Onboarding

  1. Set a password that meets the rules (8+ chars, upper, lower, number, symbol).
  2. You are redirected to the existing SSO login page.
  3. Sign in with the mock username shown in the email and the password you created.
  4. You land on the existing Agent Onboarding form.
