NFP prototype to Figma: Agent Onboarding

Everything you need to pick up the Figma file of the NFP Agent Onboarding screens: what is in it, how it is organised, what still needs doing, and how to capture more screens yourself, by hand or with your own Claude.

For UI/UX design team Date 14 Oct 2026 File version v0.1 Figma file Open in Figma

1. Summary

The NFP prototype is a set of HTML pages. We moved the whole Agent Onboarding flow into Figma as editable layers, not screenshots. That means every text, box and button can be selected and changed in Figma.

Many NFP pages are step-by-step wizards where only one step is visible at a time. We captured every step and sub-screen as its own frame, then named, labelled and grouped them in the order a user goes through them.

Important: the captured screens are a reference of the current NFP. They are not the new design. The redesign should be built with the AaNeel shadcn/ui design system, using these frames as the layout guide.

4. Working in the file

Track progress

Click the status pill on a screen label and change the Status variant in the right panel: NFP Reference, then In Design, then Ready for Dev, then Approved.

Start a redesign of a screen

  1. Duplicate the captured frame (Cmd + D) and keep the original untouched as the reference.
  2. Rebuild the copy with AaNeel design system components, using the original for layout and content.
  3. Set its status pill to In Design, and to Ready for Dev when it is handed over.

Make a colour version of the flow

  1. Select a section, for example 01-B, and duplicate it. Drag the copy below and rename it, for example 01-B · Agent Onboarding Wizard (Teal theme).
  2. With the copy selected, look at Selection colors in the right panel. It lists every colour used in all the screens.
  3. Click the NFP blues (#0D47A1, #1565C0, #0277BD) and change each to the new colour. Every screen in the copy updates at once.

Capture an extra state yourself (popups, tabs, errors)

When a page is opened through the capture link, a dark Send to Figma toolbar appears at the top of the browser:

ButtonWhat it does
Entire screenSends the whole page, as it looks right now, to the Figma file.
Select elementLets you click one part (a card, a table, a popup) and send only that.
Open fileOpens the Figma file the captures go into.
XHides the toolbar.

Open the popup, tab or error you need, then press Entire screen or Select element. After that, name it and move it into the right section using the naming rules.

The first page needs a capture link created through the Figma connection, so ask the developer or your Claude for one (see section 9).

5. Pending cleanup (v0.2)

We planned these changes, but Figma's Starter plan blocked further automated edits. They are not applied yet. You can do them by hand in about 10 minutes:

  1. Darker background. On every page, click empty canvas and set the page background to #121212. Select each section and set its fill to #1E1E1E. White screens then stand out clearly.
  2. Label text colour. On the Annotation Kit page, open Annotation/Screen Label. Set the Title text to #FFFFFF and the Source text to #98A2B3. All 24 labels update.
  3. Remove emojis from the page names: Cover & Read Me, 01 · Agent Onboarding, Annotation Kit. Also from the Read Me text.
  4. Remove long dashes (—) from labels, headers, notes and the Read Me. Use Cmd + F, search for —, and replace each with :, a comma, or brackets. Rename section 01-A · Pre-Onboarding: Invitation & Registration and frames AOW-08 · Ready to Sell (Submission Complete) and AOF-10 · Submission Confirmation.
  5. Add a Read Me change log line: 14 Oct 2026 · v0.2: Removed emojis and long dashes; dark canvas.

Leave the long dashes inside the captured screens as they are. They are the NFP prototype's own text, and the screens should keep matching the NFP.

7. How the capture works

Figma offers a free connector called the Figma MCP server. It lets an AI assistant (Claude, in Claude Code or Cursor) read and write a Figma file for you. One of its features turns a web page open in a browser into editable Figma layers.

NFP filesThe HTML prototype folder on your computer
→
Preview serverA small script that shows the pages and adds Figma's capture code
→
BrowserOpens each page at the right step and sends it
→
Figma fileThe page arrives as editable frames
  • The NFP files are never changed. The preview server adds Figma's capture code only while serving the page.
  • Wizard steps. The preview server can open a page directly at a given step (for example step 3), so every step gets its own frame.
  • Hidden browser. Captures run in a hidden Chrome window. In a normal browser, background tabs pause and the capture never finishes.
  • After capture, Claude renames the frames, groups them into sections and adds the labels.

Connect Figma to your assistant

In Claude Code, run this once in the terminal:

claude mcp add --transport http figma https://mcp.figma.com/mcp

Then start Claude, type /mcp, choose figma, pick Authenticate and log in with your Figma account in the browser.

In Cursor, open Settings, then MCP, then Add new MCP server, and paste:

{
  "mcpServers": {
    "figma": { "url": "https://mcp.figma.com/mcp" }
  }
}

Cursor shows a Login button next to the server. Log in with your Figma account.

Check it works: ask your assistant "Who am I logged in as in Figma?" It should reply with your Figma name and plan.

Then let Claude do the rest

Copy the whole block in section 9 and paste it into your Claude. It contains the instructions and both scripts, so Claude can rebuild the setup and capture any flow in the same style.

=== serve.py ===
# Serves the NFP prototype and injects Figma's capture script into every HTML page.
# Source files are never modified. Usage: python3 serve.py <nfp_dir> [port]
import http.server, os, sys
from functools import partial

TAG = b'<script src="https://mcp.figma.com/mcp/html-to-design/capture.js" async></script>'
# Optional ?run=<js> in the URL: runs that JS after load, so a wizard step or hidden
# state can be shown before Figma captures it (e.g. ?run=obGoTo(3)).
RUN = b'''<script>window.addEventListener("load",function(){var r=new URLSearchParams(location.search).get("run");
if(r)setTimeout(function(){try{(0,eval)(r);window.scrollTo(0,0)}catch(e){console.error("run failed",e)}},300)})</script>'''

class Handler(http.server.SimpleHTTPRequestHandler):
    def send_head(self):
        path = self.translate_path(self.path)
        if os.path.isdir(path):
            path = os.path.join(path, "index.html")
        if not path.endswith(".html") or not os.path.isfile(path):
            return super().send_head()
        with open(path, "rb") as f:
            body = f.read()
        body = body.replace(b"</head>", TAG + RUN + b"</head>", 1) if b"</head>" in body else TAG + RUN + body
        self.send_response(200)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.send_header("Cache-Control", "no-store")
        self.end_headers()
        import io
        return io.BytesIO(body)

root = os.path.abspath(sys.argv[1])
port = int(sys.argv[2]) if len(sys.argv) > 2 else 8090
http.server.ThreadingHTTPServer(("127.0.0.1", port), partial(Handler, directory=root)).serve_forever()

=== open_captures.py ===
# Captures NFP pages into Figma using headless Chrome (background tabs in a normal
# browser pause, so captures never fire there). One Chrome per page, run in parallel.
# Needs serve.py running on port 8090.
# Usage: python3 open_captures.py "<path?run=js>|<captureId>" ...
import os, shutil, subprocess, sys, tempfile, time, urllib.parse

def find_chrome():
    candidates = [
        os.environ.get("CHROME_PATH", ""),
        "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome",
        os.path.expandvars(r"%ProgramFiles%\Google\Chrome\Application\chrome.exe"),
        os.path.expandvars(r"%ProgramFiles(x86)%\Google\Chrome\Application\chrome.exe"),
        os.path.expandvars(r"%LocalAppData%\Google\Chrome\Application\chrome.exe"),
    ]
    for name in ("google-chrome", "google-chrome-stable", "chromium", "chromium-browser", "chrome"):
        found = shutil.which(name)
        if found:
            candidates.append(found)
    for c in candidates:
        if c and os.path.isfile(c):
            return c
    sys.exit("Google Chrome not found. Install it or set CHROME_PATH to chrome's full path.")

CHROME = find_chrome()
BASE = "http://localhost:8090/"
procs = []
for arg in sys.argv[1:]:
    page, cid = arg.rsplit("|", 1)
    ep = urllib.parse.quote(f"https://mcp.figma.com/mcp/capture/{cid}/submit?bindVariables=true", safe="")
    url = f"{BASE}{page}#figmacapture={cid}&figmaendpoint={ep}&figmadelay=3000"
    procs.append(subprocess.Popen([CHROME, "--headless=new", "--disable-gpu", "--window-size=1440,900",
        f"--user-data-dir={tempfile.mkdtemp(prefix='figcap-')}", url],
        stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL))
    print("started", page)
    time.sleep(1)
time.sleep(30)
for p in procs:
    p.terminate()
print("done")

10. Troubleshooting

What you seeWhyWhat to do
Capture stays "pending"The page was opened in a normal browser tab in the background, which pauses itUse the hidden Chrome script (open_captures.py), or keep that tab in front
"Tool call limit on the Starter plan"The monthly Figma connector limit is used upUpgrade to Professional with a Full seat, or wait for the monthly reset
"Starter plan only comes with 3 pages"Figma page limitAdd new flows as sections on the existing flow page, or upgrade
Text looks different from the prototypeThe font is not installed on the computer running FigmaInstall Poppins and the fonts used by the NFP
Only step 1 of a wizard was capturedCaptures take the page as it first loadsCapture each step using the ?run= step function (section 9, step 4)
A file:// link does not captureFigma capture only works on a web addressAlways use the preview server at localhost:8090

11. Glossary

NFPThe clickable HTML prototype of the EnrollAxis portal (about 181 pages).
MCP serverA connector that lets an AI assistant work with another tool. The Figma MCP server lets Claude read and edit Figma files.
CaptureTurning a web page into editable Figma layers.
Preview serverA small script that shows the NFP pages in a browser and adds Figma's capture code to them.
FrameOne screen in Figma.
SectionA labelled area on the Figma canvas that groups the frames of one part of a flow.
Component / instanceA reusable element (the main one) and its copies. Changing the main one updates every copy.
