HTML to Figma (Figit)

Converts a live localhost page into a Figma clipboard payload using @figit/dom-to-figma. Paste into Figma with Ctrl+V. Default desktop width is 1440px. Keep fonts, icons, images, and shadcn control sizes exact.

After opening the page, paste the inject snippet in DevTools console on that tab. Then paste the copied design into Figma with Ctrl+V.
